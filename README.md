# Job Hunter — وكيل البحث عن وظائف

وكيل يعمل كل صباح على GitHub Actions، يبحث عن وظائف تناسب رأفت أحمد: عن بعد من فلسطين، أو بانتقال إلى ماليزيا أو إندونيسيا أو تركيا. يرسل الأنسب على تيليجرام، ويحفظ تقريراً يومياً في مجلد `reports/`.

## كيف يعمل

1. **يجمع** الوظائف من خمس لوحات مجانية: Remotive وRemoteOK وHimalayas وJobicy وWe Work Remotely.
2. **يبحث في الويب** يومي الاثنين والخميس عبر Claude: وظائف بانتقال وكفالة تأشيرة في ماليزيا وإندونيسيا وتركيا، ولوحات عربية وخليجية مثل بعيد وBayt وWuzzuf.
3. **يستبعد** ما رآه سابقاً، والمكرر بين اللوحات، والإعلانات الأقدم من 21 يوماً، والوظائف المحصورة بدول أخرى، والوظائف غير الهندسية أو المبتدئة.
4. **يقيّم** كل وظيفة جديدة من 0 إلى 100 مقابل ملفك في `profile.json`، ويحكم إن كان توظيفك ممكناً من فلسطين أو بكفالة.
5. **يرسل** ما فوق 70 على تيليجرام مع سبب المناسبة والأهلية والرابط. التقرير الكامل فيه أيضاً جملتان جاهزتان بالإنجليزية تبدأ بهما طلبك.

## الإعداد (مرة واحدة، 10 دقائق)

1. **مفتاح Claude API**: من [console.anthropic.com](https://console.anthropic.com) ثم API Keys. ضع رصيداً صغيراً، مثلاً 10 دولارات.
2. **بوت تيليجرام**:
   - افتح [@BotFather](https://t.me/BotFather) وأرسل `/newbot` واحفظ الـ token.
   - أرسل أي رسالة لبوتك الجديد، ثم افتح هذا الرابط بعد وضع الـ token:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
     وانسخ الرقم الموجود في `"chat":{"id": ...}`.
3. **في المستودع**: Settings ثم Secrets and variables ثم Actions، وأضف ثلاثة Secrets:

   | الاسم | القيمة |
   |---|---|
   | `ANTHROPIC_API_KEY` | مفتاح Claude |
   | `TELEGRAM_BOT_TOKEN` | token البوت |
   | `TELEGRAM_CHAT_ID` | رقم المحادثة |

4. **أول تشغيل**: تبويب Actions ثم Job hunt ثم Run workflow. أول تشغيل يقيّم عدداً أكبر لأن كل الوظائف جديدة.

بعدها يعمل وحده كل يوم الساعة 7 صباحاً بتوقيت فلسطين.

## التخصيص

- **ملفك**: عدّل `profile.json`. أضف حداً أدنى للراتب في `min_salary_usd_per_year`، أو غيّر المدن والمهارات.
- **إعدادات اختيارية** في Settings ثم Variables، وكلها لها قيم افتراضية:

  | المتغير | الافتراضي | المعنى |
  |---|---|---|
  | `MIN_SCORE` | 70 | أقل درجة تُرسل على تيليجرام |
  | `MAX_ALERTS` | 10 | أقصى عدد وظائف في رسالة اليوم |
  | `MAX_SCORE_JOBS` | 120 | أقصى عدد وظائف تُقيَّم في التشغيل الواحد |
  | `WEB_SEARCH_DAYS` | `1,4` | أيام بحث الويب: 0 الأحد حتى 6 السبت، أو `all` أو `never` |
  | `CLAUDE_MODEL` | `claude-opus-5-5` | النموذج المستخدم |

## التكلفة التقديرية

GitHub Actions مجاني لهذا الحجم. تكلفة Claude تقديرية، وكل تشغيل يطبع تكلفته الفعلية في التقرير:

| البند | التقدير |
|---|---|
| تقييم يومي عادي | حوالي 0.20 دولار |
| بحث الويب مرتين أسبوعياً | حوالي 0.80 دولار للمرة |
| الشهر تقريباً | 10 إلى 15 دولاراً |

لتخفيضها: اجعل `WEB_SEARCH_DAYS` يوماً واحداً، أو خفّض `MAX_SCORE_JOBS`، أو جرّب `CLAUDE_MODEL=claude-sonnet-5-5`.

## التشغيل محلياً

```bash
npm install
npm run dry-run          # بيانات تجريبية، بلا مفتاح ولا تيليجرام
npx tsx src/selftest.ts  # اختبار منطق البحث والتقييم بردود محاكاة
npm run check-sources    # يتأكد أن اللوحات المجانية تستجيب
ANTHROPIC_API_KEY=... npm run hunt -- --web
```

## ملاحظات

- اللوحات المجانية تطلب الإشارة إلى المصدر، والتقارير تحتفظ برابط كل إعلان الأصلي.
- `data/seen.json` يتذكر الوظائف 90 يوماً حتى لا تصلك مرتين.
- لإيقاف الوكيل: Actions ثم Job hunt ثم Disable workflow.
